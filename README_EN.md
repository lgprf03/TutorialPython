<h1>Tutorial for Learning Python 🤓</h1>

<p aligh="justify">This tutorial is designed to teach basic to intermediate concepts to people interested in discovering the power of the language when it comes to implementing algorithms. The repository will be updated as needed to accommodate new versions or requirements that arise over time.</p>
<br>
<p aligh="justify">It is hoped that this will serve as a way to encourage new users of the language to design their own solutions and learn more about Python. Best wishes 🤗—and happy coding.</p>

<ul>
  <li>Basic Concepts: Variables, Data Input, Arithmetic and Logical Operators, `it`; `while`; `for` Statements, Functions, and the `math` Library</li>
  <li>Basic to Intermediate Concepts: Exceptions, Classes and OOP, Imports, and Flat File Handling</li>
  <li>Knowledge of key libraries for data handling and analysis</li>
