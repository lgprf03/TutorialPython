<h1>Tutorial para Aprender Python 🤓</h1>

<p aligh="justify">El siguiente tutorial esta enfocado en enseñar conocimientos básicos-intermedios a personas interesadas en conocer la pontencia del leguaje a la hora de realizar algoritmos. El repositorio se verá modificado en caso de ajustarse a las versiones o las necesidades que vayan surgiendo con el paso del tiempo.</p>
<br>
<p aligh="justify">Se espera que este sea un medio para impulsar a nuevos usuarios del lenguaje a diseñar sus propias soluciones y conocer más hacerca de Python. Un abrazo 🤗 y a practicar.</p>

<h2>Capsulas del tutorial ✊</h2>
<ul>
  <li>Conocimientos Básicos: Variables, Ingreso de datos, Operadores Aritméticos y Lógicos, Clausulas it; while; for, Funciones y La Librería Math</li>
  <li>Conocimientos Básico-Intermedio: Excepciones, Clases y POO, Importaciones y Manejo de Archivos Planos</li>
  <li>Conocimientos en librerías importantes para el manejo y análisis de datos</li>
  <li>Conocimientos para interactuar con una base de datos y realizar un CRUD</li>
  <li>Pasos para realizar un entorno virtual y su funcionamiento</li>
</ul>
